Pour ton joueur, qu'est-ce que ça change ?

Ce qui change
  • Le score de chaque jeu s'affiche en direct.
  • Un peu plus de balles de break par match, comme au vrai tennis.
  • Un match long et accroché fatigue plus ton joueur qu'un match vite plié.
Ce qui ne change pas
  • Tes chances de gagner un match.
  • L'importance du mental sur les balles de break.
  • La progression de ton mental et la fatigue, en moyenne.
  • Les tie-breaks, les styles de jeu et les blessures.

Les trajectoires, la longueur des échanges, les aces et les fautes sont tirés au hasard pour l'image : ils n'ont aucun effet sur le résultat. Seul le vainqueur du point est décidé par le moteur, avec la même formule que dans la présentation du projet.

Les formules exactes

N = niveau de jeu (normal) · M = niveau « points importants » (N − forme + mental courant) · s = serveur, r = relanceur

R(écart) = chance de gagner selon la règle : 50 % + écart × 0,16 jusqu'à 25 · 54 % + (écart − 25) × 0,1 jusqu'à 50 · 56,5 % + (écart − 50) × 0,05 jusqu'à 100 · 59 % + (écart − 100) × 0,025 au-delà · 95 % maximum

Aujourd'huiDemain
Point normal Pas de point. Chaque jeu commence par un tirage « service » : le serveur le gagne avec R(Ns − Nr) et remporte alors le jeu. S'il le perd : balle de break. Chaque point : le serveur le gagne avec 50 % + 0,58 × (R(Ns − Nr) − 50 %) + 6,9 %
Point important Le serveur le gagne avec R(Ms − Mr) Le serveur le gagne avec (point normal) + 1,2 × (R(Ms − Mr) − R(Ns − Nr))
Quels points sont importants Chaque balle de break (après un tirage « service » perdu) ; le tirage « service » lui-même si le jeu donnerait le set ou le match au serveur. Chaque point où le relanceur peut gagner le jeu (0-40, 15-40, 30-40, avantage relanceur) ; chaque point où le serveur peut gagner le jeu, si ce jeu lui donnerait le set ou le match.

Et en 3D ?

Le même match, cette fois dans un stade en 3D qui change selon le tournoi : petit bol de béton pour un 250, grand bol sous deux toits pour un 500, stade rond pour un 1000, et les quatre courts centraux des Grands Chelems. Les tribunes se remplissent selon la catégorie, chaque Grand Chelem a son marqueur télé, et tu peux choisir ton angle en faisant glisser l'image. Le vainqueur de chaque point vient toujours de la même formule.

Cette maquette demande plus de ressources à ton appareil. Si l'image reste vide, la 3D n'est pas disponible sur ton navigateur.

Étude du 4 novembre. Rien n'est encore modifié dans le jeu.
